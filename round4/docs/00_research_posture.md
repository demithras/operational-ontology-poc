# 00 Research posture

Round 4 is a research contract, not a sales document for the EOO (Executable Operational Ontology) pattern. Its job is to find the smallest experiment that can kill the value claim.

## The honest history

| Round | Result | What it taught |
|---|---|---|
| 1, exp-003 | H1-H10 and H12-H14 SUPPORTED, H11 REJECTED | The relational baseline reached parity with the ontology on correctness and forensics. |
| 2 | H22 and H22w REJECTED | The ontology tax does not repay with domain variety. |
| 3 | H23-H29 SUPPORTED for both tracks, H30 NOT RUN | The machinery works, but both variants sit at the ceiling, so no measured security value. |

Round 4 does not rescue these claims. It changes the domain from manufacturing to agent-run IT work, decided by the author on 2026-10-28, replacing the earlier Attractor-game plan.

## Why this domain could be different

AI agents working across several repositories fail in ways a single-repo conventional setup does not name: two agents take one item, an agent reports done when it is not, a blocker sits in another repository. These are measurable by an independent observer. Whether the pattern beats beads plus GitHub controls on them is open.

## Rules of the posture

1. The strongest rival is always "the conventional stack already does this".
2. Parity is a result, not a failure of the experiment. Write "no advantage measured".
3. Two ledgers: implementation status (GREEN or RED) and hypothesis verdict (SUPPORTED, REJECTED, INCONCLUSIVE or INVALID).
4. The round is pilot-first and may stop after the pilot.
5. No claim without an independent observer. An agent's report is never truth.
6. No post-reveal scope surgery: a fault class that does not discriminate is not removed afterwards.
