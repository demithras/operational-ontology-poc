# Round 4 hypotheses

This round contains H31-H36. H31 and H32 test coordination of AI agents across projects. H33, H34 and H35 test control of what agents may do and what counts as true. H36 is the only comparative-value claim.

Authoritative claims and evaluator conditions live in each `contract.json`; README files are generated human-readable views.

Every contract names the conventional stack as a rival. Parity with the conventional stack is a reject for H36, and for H31-H35 it is recorded as "no advantage measured".
