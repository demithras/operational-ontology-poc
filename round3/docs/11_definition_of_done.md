# 11 — Definition of done

The pack is ready to freeze when:

- H23-H30 contracts validate;
- thresholds are explicit and reviewed;
- attack classes and survivability envelope parse and are non-empty;
- upstream Round 2 evidence is pinned;
- fair-baseline rules are frozen;
- every H23-H29 major property has a mutation proof requirement;
- H30 cannot become SUPPORTED without >=5 attack classes and >=40 blind realistic tasks;
- safety and safe progress are measured separately;
- no candidate log is the sole external-effect oracle;
- protocol can be frozen by hash.

Round 3 implementation is done only when every active hypothesis has an immutable verdict or an explicit dependency stop. A rejected H30 is a valid successful research outcome.
