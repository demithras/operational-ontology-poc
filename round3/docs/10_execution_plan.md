# 10 — Execution plan: armor kill-chain, not feature roadmap

## Gate 0 — freeze threat model and trust splits

Freeze P1-P6, A1-A10, survivability envelope, low-observable channels, integrity-anchor placement, external-effect oracle and baseline fairness before security implementation changes.

## Gate 1 — H23

Attack the existing agent/tool/Engine boundary. If a compromised caller can create a forbidden effect, stop downstream claims that assume effect containment.

## Gate 2 — H24 + H27

Establish temporal authority integrity and historical provenance integrity. These are separate: a perfectly auditable stale permission is still unsafe.

## Gate 3 — H25 + H26

Test richer constitutional authority and knowledge sovereignty only after basic capability lifecycle is credible.

## Gate 4 — H28

Move the attacker to the system boundary: hostile adapters and false external outcomes.

## Gate 5 — H29

Combine faults and bounded compromise. Track safety and safe progress separately.

## Gate 6 — H30

Only after the mechanisms work may the project claim they are worth the premium. Freeze a strong conventional baseline, reveal blind adversarial tasks and compare the trade-off frontier.
