# 05 — Knowledge sovereignty

Knowledge sovereignty is stronger than write authorization.

For Round 3, a protected fact includes object properties, object existence, relationship existence, provenance actors/evidence, tool/action availability and other semantic structure marked by the frozen disclosure contract.

H26 uses an application-layer noninterference test:

> If two worlds are identical in everything a principal is allowed to know, but differ in protected facts, the principal's supported low-observable outputs should be identical unless the disclosure contract explicitly permits that distinction.

Supported low channels include queries, generated tools/schemas, errors, subscriptions/events and provenance APIs.

Out of scope for this round: hardware/cache side channels, packet-size/traffic analysis, unrelated model-training memorization and compromised client devices. These can become later hypotheses; they are not silently claimed here.
