# H25 — Constitutional authority topology is executable without domain-specific privilege code

## Claim

A generic Paladin authority model can represent and execute legitimacy, scope, precedence, delegation, review/appeal, quorum and bounded emergency authority across different domains without domain-specific Engine branches, while leaving discretionary content judgment to explicit external or human oracles.

## Strong null / rival

Constitutional authority is too contextual to be a generic executable subsystem; real cases require hidden domain code or the Engine silently substitutes procedural authority for substantive judgment.

## Mechanism under test

The Engine computes authority validity and procedural legitimacy from generic typed relations; discretionary merit/content decisions enter as signed or attributable oracle facts and are never fabricated by generic authority logic.

## Primary falsifiers

- A registered governance model requires a new domain-specific Engine branch or hidden privilege handler.
- The Engine grants procedural legitimacy differently from the independent oracle.
- The Engine manufactures a discretionary merit judgment that was not supplied by an authorized oracle/human input.
- Emergency authority persists or expands outside its declared scope/expiry.

## Experiment

Cross-governance differential experiment over generated constitutional authority graphs and explicit discretionary-oracle boundaries.

1. Freeze the minimal authority-topology vocabulary and three governance-model fixtures before implementation changes.
2. Build an independent pure evaluator for legitimacy, precedence, quorum, appeal and emergency scope.
3. Generate at least 10,000 authority cases including conflicts, cycles and missing discretionary facts.
4. Audit Engine/compiler import closure for domain-identity privilege branches.
5. Require explicit unresolved/oracle-needed outcomes where procedural rules cannot determine substantive merit.
6. Inject precedence, quorum, emergency-expiry and fabricated-judgment mutants.

## Independent oracle

Pure constitutional procedure evaluator plus explicit opaque merit-judgment inputs; the oracle never imports domain or Engine code.

## Fair baseline

Conventional policy engine with equivalent governance facts and domain policy modules; compared for complexity and correctness, with H30 deciding value.

## Stop rule

- If content/merit authority repeatedly leaks into generic Engine semantics, keep the procedural authority boundary and reject the stronger constitutional-computation claim.
